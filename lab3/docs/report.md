Промпт для создания приложения в Bubble:  
Создай приложение на тему «Система интеллектуальной поддержки стартап-проектов на ранней стадии» (прототип).

Пусть этот сайт будет требующим регистрацию (с упрощённой авторизацией: роль «Основатель» или «Специалист» при регистрации).

Обязательно укажи в заготовке следующую строку: «ТВП: Волчкевич»

Страницу обязательно создай по структуре header + body + footer. Обязательно укажи в заготовке следующую строку: «ТВП: <Фамилия>» (в подвале или в шапке сайта, отдельным текстовым элементом).

Добавь несколько интерактивных элементов, реализующих CRUD.

Расширенное описание темы

Приложение — веб-платформа для основателей стартапов и специалистов, желающих присоединиться к проекту. Платформа объединяет три функции:

Проверка идеи — основатель вводит описание идеи, система показывает список уже существующих аналогов/конкурентов (по заранее подготовленной базе данных).

Верификация названия — основатель вводит название стартапа, система проверяет, занято ли оно: товарные знаки, домены, существующие компании/бренды (по базе данных).

Командообразование — основатель публикует заявку на участие в проекте (описание, нужные роли), специалисты видят заявки и откликаются с предложением помощи.

Роли пользователей

Основатель (founder) — создаёт проект, проверяет идею и название, публикует заявку на команду.

Специалист (contributor) — просматривает ленту заявок, откликается на них.

Функционал MVP (с CRUD)

Регистрация/вход (упрощённо, на встроенной авторизации Bubble).

Create: создание проекта (название, описание идеи, нужные роли), создание отклика на заявку.

Read: лента проектов/заявок; страница проекта; список аналогов по идее; результаты проверки названия; список моих откликов.

Update: редактирование своего проекта (название, описание, роли); редактирование профиля.

Delete: удаление своего проекта; удаление своего отклика.

Проверка идеи: поиск по базе аналогов (Data Type «Аналог»).

Проверка названия: поиск по базе названий/доменов (Data Type «Название»).

Структура страниц (header + body + footer на каждой)

Header: логотип, название приложения, навигация (Главная, Проекты, Проверка идеи, Проверка названия, Профиль), кнопки Вход/Регистрация или Выход. Строка «ТВП: <Фамилия>».

Body: основной контент страницы.

Footer: краткое описание проекта, контакт, строка «ТВП: <Фамилия>».
