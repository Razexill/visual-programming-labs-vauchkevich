# Flowchart: Расчёт стоимости поездки в каршеринге

```mermaid
flowchart TD
    A([Начало]) --> B[Получить данные поездки: время, пробег, тариф]
    B --> C[Базовая стоимость = время × тариф_мин + пробег × тариф_км]
    C --> D{Есть скидка?}
    D -- Да --> E[Применить скидку]
    D -- Нет --> F[Скидка не применяется]
    E --> G[Итоговая стоимость]
    F --> G
    G --> H{Достаточно средств?}
    H -- Да --> I[Списать средства]
    I --> J[Сформировать чек]
    J --> K([Конец])
    H -- Нет --> L[Уведомить клиента о задолженности]
    L --> K
